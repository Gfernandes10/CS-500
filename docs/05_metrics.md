# Phase E - Metrics and Evaluation

## Objective
Create a repeatable metrics pipeline for command/telemetry/video evaluation and final report analysis.

## Experiment and Analysis Workflow
1. Real-drone experiment procedures are defined in [08_experiments.md](08_experiments.md).
2. CSV summaries and plots can be generated with [analyze_metrics.ipynb](../notebooks/analyze_metrics.ipynb).
3. A synthetic example dataset is available at [sample_metrics.csv](../results/sample_metrics.csv).
4. A generated example plot is available at [sample_metrics_plot.png](../results/sample_metrics_plot.png).

## Current Implementation (E1)
1. Standalone `tello_viewer` has been retired from the active build surface.
2. Viewer/runtime metrics now live in the Qt control panel (`tello_control_panel`) through the central `MetricsCollector`.
3. When panel CSV export is enabled, command rows and periodic vision rows use the shared metrics schema.

## Current Implementation (E2)
1. CLI video-watch metrics export to CSV is implemented.
2. Export is enabled with command-line option:
- --metrics-csv PATH
- Optional E4 experiment metadata:
- --test-id ID
- --scenario NAME
- --notes TEXT

Example:
- ./build/tello_cli --video-watch --interval-ms 1000 --duration-s 30 --metrics-csv results_cli_video.csv --test-id E4-002 --scenario normal --notes "video baseline"

## CSV Schema (Central MetricsCollector)
The active command/video/control-panel exports now use the header generated by `MetricsCollector::toCsvHeader()`.

Major field groups:
1. Experiment metadata (`test_id`, `scenario`, `notes`, `run_mode`)
2. Runtime index (`elapsed_ms`, `attempt`)
3. Command metrics (samples, success/failure counts, latency aggregate, latest command/result/response)
4. Telemetry receiver stats
5. Video UDP receiver stats
6. H264/NAL assembler and classification stats
7. Decoder stats
8. Display state (`frame_width`, `frame_height`, `keyframes`, `paused`, `overlay_enabled`)
9. Recovery/event/connection-state fields
